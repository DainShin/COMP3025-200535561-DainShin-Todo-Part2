# TO Do List App
This Android application is a task management app built with Firebase Firestore and ViewModel, allowing users to add, update, and delete tasks. 
It utilizes RecyclerView and DiffUtil for efficient list updates and dynamically displays deadline warnings based on selected due dates. 
Task status is updated in real time, and users can intuitively mark tasks as completed using checkboxes.
